Status verwijderen via de Qatchr API. De specificatie toont de exacte parameters, invoer en uitvoer.

## Toegang

Stuur `Authorization: Bearer <access-token>` en `X-Organization-Id` mee.

Vereist recht: `manage-pipelines` binnen scope `qatchr`.

Een `require_subscription`-controle vereist algemene Qatchr-toegang voor deze mutatie.

## Bron

Swagger-operation: `delete_status_api_v1_statuses__status_id___delete`. Route: `app/api/v1/statuses.py` (`delete_status`).
