---
title: "Download-URL ophalen"
description: "Vraag een tijdelijke download-URL voor een document op."
openapi: "/openapi/qatchr.json GET /api/v1/documents/{document_id}/url"
---

De response is een JSON-string met een signed URL. De URL is vijf minuten geldig; vraag een nieuwe URL op als de bestaande is verlopen.

## Toegang

De route heeft geen expliciete `check_permission`-decorator. Gebruik de organisatie- en gebruikersheaders die bij de parameters staan. Aanvullende gatewaycontroles hangen af van de deployment; zie [authenticatie](/guides/authentication).

## Meer uitleg

Zie [Documenten](/guides/documents) voor de volledige werkwijze.

## Bron

Swagger-operation: `get_document_url_api_v1_documents__document_id__url_get`. Route: `app/api/v1/documents.py` (`get_document_url`).
