Deze call vereist `X-Lifecycle-Key`. Lifecycleondersteuning staat standaard uit; de handler retourneert dan `503`. De organisatievariant inventariseert resourceaantallen.

## Toegang

Dit is een interne servicecall. Gebruik `X-Lifecycle-Key`; een normale bearer-token vervangt deze sleutel niet. Zie [organisatielifecycle](/guides/organization-lifecycle).

## Meer uitleg

Zie [Organisatielifecycle](/guides/organization-lifecycle) voor de volledige werkwijze.

## Bron

Swagger-operation: `ready_organization_api_v1_organization_lifecycle_ready__organization_id__get`. Route: `app/services/organization_lifecycle.py` (`ready_organization`).
