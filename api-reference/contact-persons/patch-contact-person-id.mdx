Contactpersoon wijzigen via de Qatchr API. De specificatie toont de exacte parameters, invoer en uitvoer.

## Toegang

Stuur `Authorization: Bearer <access-token>` en `X-Organization-Id` mee.

Vereist recht: `manage-relations` binnen scope `qatchr`.

Een `require_subscription`-controle vereist algemene Qatchr-toegang voor deze mutatie.

## Bron

Swagger-operation: `update_contact_person_api_v1_contact_persons__contact_person_id___patch`. Route: `app/api/v1/contact_persons.py` (`update_contact_person`).
