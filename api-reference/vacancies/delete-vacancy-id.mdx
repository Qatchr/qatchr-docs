Vacature verwijderen via de Qatchr API. De specificatie toont de exacte parameters, invoer en uitvoer.

## Toegang

Stuur `Authorization: Bearer <access-token>` en `X-Organization-Id` mee.

Vereist recht: `manage-vacancies` binnen scope `qatchr`.

Een `require_subscription`-controle vereist algemene Qatchr-toegang voor deze mutatie.

## Bron

Swagger-operation: `delete_vacancy_api_v1_vacancies__vacancy_id___delete`. Route: `app/api/v1/vacancies.py` (`delete_vacancy`).
