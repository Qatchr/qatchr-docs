Kandidaat wijzigen via de Qatchr API. De specificatie toont de exacte parameters, invoer en uitvoer.

## Toegang

Stuur `Authorization: Bearer <access-token>` en `X-Organization-Id` mee.

Vereist recht: `manage-candidates` binnen scope `qatchr`.

Een `require_subscription`-controle vereist algemene Qatchr-toegang voor deze mutatie.

## Bron

Swagger-operation: `update_candidate_api_v1_candidates__candidate_id___patch`. Route: `app/api/v1/candidates.py` (`update_candidate`).
