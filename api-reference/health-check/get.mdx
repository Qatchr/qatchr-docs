Geeft `{"message":"OK"}` terug. Deze handler controleert geen database, IAM, opslag of achtergrondwerkers; een succesvolle response bewijst alleen dat de handler bereikbaar is.

## Toegang

De route definieert geen permission-check of organisatieheader.

## Bron

Swagger-operation: `health_check_health_check_get`. Route: `main.py` (`health_check`).
